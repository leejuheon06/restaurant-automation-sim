# Coding Standard

## 1. 개요 (Overview)

본 문서는 프로젝트 개발 과정에서 코드의 일관성, 가독성, 안정성 및 유지보수성을 확보하기 위해 참고하는 코딩 표준을 정리한 문서이다.

C++ 및 Python 개발 시 다음 코딩 표준을 참고하며, 프로젝트의 개발 환경과 요구사항에 맞게 적용한다.

## 2. 참고 코딩 표준 (References)

| **언어** | **코딩 표준** | **주요 참고 항목** |
| --- | --- | --- |
| C++ | MISRA C++ | 코드 안전성, 잠재적 오류 예방 |
| Python | Google Python Style Guide | 네이밍 규칙, 코드 포맷, 주석, 함수 및 클래스 구조 |

## 3. 적용 방침 (Application Policy)

- 각 언어별 코딩 표준을 참고하여 코드 작성 규칙 수립
- 코드의 가독성 및 유지보수성을 고려한 일관된 작성 방식 적용
- 코드 리뷰 및 품질 검증 과정에서 참고 기준으로 활용
- 프로젝트 특성에 따라 필요한 규칙을 선택적으로 적용

※ 본 문서는 코딩 표준의 전체 규칙 준수를 의미하지 않으며, 프로젝트 개발 시 참고하는 가이드라인을 정의한다.
