# 주제1 \- UR 수정본 v2

11/11: 전체 시나리오 v2 기반으로 작성

로봇팔과 자율주행 AMR을 활용하여 고객 안내, 음식 주문, 조리 및 서빙 과정을 자동화하는 무인 레스토랑 서비스 중앙관제을 구현하는 프로젝트이다.

고객이 매장에 입장하면 AMR이 이용 가능한 테이블로 안내하고, 고객은 테이블에서 원하는 메뉴를 주문한다. 주문 정보에 따라 로봇팔이 볶음밥 또는 튀김요리의 조리 작업을 수행하며, 조리가 완료되면 AMR을 호출하여 완성된 음식을 적재한다. 이후 AMR은 주문한 고객의 테이블까지 자율주행하여 음식을 서빙하고, 고객의 수령 완료 확인 후 다음 임무를 수행하거나 지정된 대기 위치로 복귀한다.

이를 통해 로봇팔과 AMR 간의 작업 연계, 자율주행 및 정밀 정차, 다중 로봇 임무 배정과 통합 관제 기능을 구현하고, 고객 안내부터 주문, 조리 및 서빙까지 이어지는 레스토랑 서비스 과정의 무인화 가능성과 중앙관제 운영 성능을 검증한다.

AMR은 로봇팔이 부착된 형태로 통합해서 AMR로 표기함.

| **UR ID** | **Category** | **UR Description** | **Reporter** |
| --- | --- | --- | --- |
| UR-01 | 고객 인원수 확인 | 중앙관제는 고객의 이용 인원수를 확인하고 좌석 안내 서비스를 제공할 수 있어야 한다. |  |
| UR-02 | 빈 테이블 확인 및 배정 | 중앙관제는 테이블 이용 상태를 확인하고 고객의 이용 인원수를 수용할 수 있는 빈 테이블을 중복 없이 배정할 수 있어야 한다. |  |
| UR-03 | AMR 고객 안내 | AMR은 고객의 동행 상태를 확인하면서 후진으로 배정된 테이블까지 안내하고 장애물을 회피할 수 있어야 한다. |  |
| UR-04 | 태블릿 기반 메뉴 선택 | 고객은 배정된 테이블의 주문 화면에서 후라이드치킨, 양념치킨, 볶음밥 메뉴와 수량을 선택할 수 있어야 한다. |  |
| UR-05 | 주문 정보 확인 및 확정 | 고객은 주문 확정 전에 선택한 메뉴, 수량 및 테이블 정보를 확인하고 주문을 확정할 수 있어야 한다. |  |
| UR-06 | 주문 접수 및 진행 상태 확인 | 중앙관제는 고객이 확정한 주문을 접수해야 하며, 고객은 주문 화면을 통해 해당 주문의 접수 여부와 진행 상태를 확인할 수 있어야 한다. |  |
| UR-07 | 치킨 자동 조리 | 중앙관제는 주문한 치킨 종류와 수량에 따라 로봇팔 A·B의 협업으로 사전에 준비된 재료를 자동 조리할 수 있어야 한다. |  |
| UR-08 | 볶음밥 자동 조리 | 중앙관제는 주문 수량에 따라 로봇팔 A·B의 협업으로 사전에 준비된 볶음밥 재료를 자동 조리할 수 있어야 한다. |  |
| UR-09 | AMR 음식 적재·서빙 | AMR은 완성된 음식을 부착된 로봇팔로 적재하고 해당 주문의 테이블 서빙 위치까지 운반할 수 있어야 한다. |  |
| UR-10 | 음식 도착 안내 | 중앙관제는 AMR의 목적지 도착이 확인되면 해당 테이블의 주문 화면을 통해 고객에게 음식 도착 및 서빙 진행 상태를 안내할 수 있어야 한다. |  |
| UR-11 | 음식 자동 하역 | 로봇팔 부착 AMR은 지정된 서빙 위치에 정차한 뒤 부착된 로봇팔로 적재된 음식을 테이블에 자동 전달할 수 있어야 한다. |  |
| UR-12 | 고객 이용 종료 확인 | 중앙관제는 고객의 태블릿 이용 종료 입력 또는 고정 의자의 QR 인식 결과를 활용해 테이블 이용 종료 여부를 판단할 수 있어야 한다. |  |
| UR-13 | 테이블 회수 완료·가용 전환 | 중앙관제는 식기 회수가 완료된 테이블을 재배정 가능한 상태로 전환할 수 있어야 한다. |  |
| UR-14 | 통합 관제 현황 확인 | 관리자는 관제 중앙관제을 통해 고객 안내, 테이블 이용, 주문, 조리, 서빙, 식기 회수 및 로봇 운용 현황을 통합 확인할 수 있어야 한다. |  |
| UR-15 | 테이블 이용 현황 관리 | 관리자는 테이블별 이용 상태와 고객 안내 진행 상태를 확인하고, 중복 배정이 발생하지 않는 범위에서 이용 상태를 변경할 수 있어야 한다. |  |
| UR-16 | 주문 및 조리 현황 관리 | 관리자는 테이블별 주문 내역과 주문에 포함된 메뉴별 조리 진행 상태를 확인할 수 있어야 한다. |  |
| UR-17 | AMR 운용 현황 관리 | 관리자는 AMR별 현재 위치, 배터리, 운용 상태, 현재 임무 및 부착 로봇팔의 작업·오류 상태를 확인할 수 있어야 한다. |  |
| UR-18 | AMR 임무 수동 제어 | 관리자는 AMR의 임무를 일시 중단하거나 중단된 임무를 재개할 수 있어야 하며, 기존 임무의 중단 또는 취소가 확인된 경우 재할당이 가능한 임무를 다른 가용 AMR에 재할당할 수 있어야 한다. |  |
| UR-19 | 로봇 이상 상태 확인 | 관리자는 로봇팔 또는 AMR에 이상이 발생하면 해당 장치의 식별 정보, 오류 내용, 발생 시각 및 관련 작업을 확인할 수 있어야 한다. |  |
| UR-20 | 작업 실패 및 복구 관리 | 관리자는 조리, 고객 안내 또는 서빙 작업이 실패하면 실패 원인과 작업 진행 상태를 확인하고, 재시도 가능한 작업의 재시도 또는 취소를 요청할 수 있어야 한다. |  |
| UR-21 | AMR 복귀·충전·가용 상태 관리 | 관리자는 각 AMR의 충전 위치 복귀 여부, 배터리 잔량, 실제 충전 여부 및 임무 가용 여부를 확인할 수 있어야 한다. |  |
| UR-22 | 작업 이력 관리 | 관리자는 주문 접수, 조리, 서빙, 고객 안내 및 AMR 임무 수행 이력을 기간, 작업 유형 및 처리 결과에 따라 조회할 수 있어야 한다. |  |
