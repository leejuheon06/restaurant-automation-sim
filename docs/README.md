## 새 문서 정리 규칙

- `TROUBLESHOOTING.md`는 수정·이동·삭제하지 않는다.
- 파일명 `_1`, `_2`만으로 중복이라고 판단하지 않는다. 날짜와 테스트 항목, 실행 ID, 조건을 대조한다.
- 같은 실험의 중복 설명은 합치되 실행별 측정값, 단위, 반복 횟수, 원본 로그 경로, 배터리, 무효 사유와 미실시 항목을 보존한다. 조건이 다른 결과를 같은 표본으로 합산하지 않는다.
- 설정 변경은 기존값 → 변경값 → 근거 실측 → 결정 주체 → 적용·재시험 상태로 기록한다. 제안, 사용자 결정, 코드 반영, 실기기 검증을 구분한다.
- 수정 전후 수치를 덮어쓰지 않는다. 정정은 어떤 측정·판정을 대체하는지 남긴다. 측정하지 않은 값은 추정으로 채우지 않는다.
- 합친 뒤 고유 내용 보존과 참조를 확인한 문서만 삭제한다. 다른 세션이 편집 중이면 원본 변경 여부를 재확인한다. 보호 문서의 참조를 깨뜨리는 삭제는 보류한다.
