> 2026-11-26에 최종 기준이 Confluence I/F v0.3 최종 판으로 바뀌어 이름 8건을 되돌림(`/frybot/check_in`, `/fms/submit_task` 등). 아래 본문은 그날의 기록입니다. 지금 이름은 [INTERFACES.md](2026-11-23_INTERFACES_OLD.md), [2026-11-26_IF_V03_NAME_REVERT_PLAN.md](2026-11-26_IF_V03_NAME_REVERT_PLAN.md) 참고.

작성: 2026-11-25. 처음에는 ROS 2 항목(14~37)만 대조했고, 같은 날 사용자 지시로 웹(01~13)과 AI·영상·DB·장비 운용(38~44)까지 넓혔습니다(파일 이름도 `2026-11-25_IF_ROS2_CHECK.md`에서 바꿈). 이전 대조는 [2026-11-23 전체 비교](2026-11-23_IF_COMPARE_ALL.md)(옛 번호 49건)이고, 코드의 실제 연결은 [인터페이스 연결 구조](2026-11-23_INTERFACES_OLD.md)에 있습니다.

- **기준(2026-11-25 사용자 결정): `FryBot 통합 인터페이스 정의서 v0.2`가 최종입니다.** 이름이 다른 것은 v0.2 이름으로 코드를 고치고, 기능·연결이 다른 것은 사용자가 판단합니다.
- 읽은 Confluence 페이지(조회만 하고 수정하지 않음):
  - `FryBot 통합 인터페이스 정의서 v0.2` (판 10, 2026-11-24 17:39 수정)와 그 아래 상세 정의서 `01)`~`44)` 전부, 참조 5건
  - `1) FryBot I/F 목록` (판 11, 2026-11-25 10:56 수정)
  - `FryBot I/F 목록 정정 · 통행 허가와 서빙` (판 1, 2026-11-24 17:44)
  - 참고로만: `FryBot 인터페이스 정의서 v0.3`(v0.2의 하위 페이지). 기준이 아니며 v0.2와 다른 점만 10장에 남김
- 코드: `src/frybot`(`jazzy-port`, 미커밋 변경 포함). `frybot_interfaces`의 정의 파일, 각 노드가 서비스·액션·토픽을 만드는 줄, `web_service`의 HTTP 경로 표, `central_control`의 AI 결과 수신, `frybot_ai`의 `guest_tracker`, 카메라 송신 코드, `db.py`를 읽어 대조했습니다.
- 확인 범위: 문서와 코드를 읽어 비교했습니다. 실행 그래프와 실기기로는 확인하지 않았습니다(확인 필요). 정의서가 근거로 드는 GitHub 저장소(`roscamp-repo-1`)의 OpenAPI·IDL도 열어 보지 않았습니다.

이름만으로 정할 수 없어 목록에서 뺀 것:

- 28번 `/{pinky}/serving_arm/arm_job` → `/{pinky}/arm/transfer_object`: 24번 정정 페이지가 지금 이름을 현행으로 적음.
